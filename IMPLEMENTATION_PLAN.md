## Theory Summary (Quick Reference)

**Simplified RTE (no scattering in gas plumes):**
```
dIη/ds = κη · Ibη − κη · Iη
```
- `Iη` = spectral intensity along ray direction `ŝ`
- `Ibη` = Planck blackbody function at local temperature
- `κη` = spectral absorption coefficient (from HITEMP)

**IR Bands of Interest:**
| Band | Wavenumber (cm⁻¹) | Wavelength (µm) | Primary Species |
|------|-------------------|-----------------|-----------------|
| MWIR | 2000–3333 | 3–5 | CO₂, CO |
| MIR Fund. | 1000–2000 | 5–10 | CO₂, H₂O |
| LWIR | 714–1250 | 8–14 | H₂O, soot |

**HITEMP line intensity temperature scaling:**
```
S(T) = S(296) × [Q(296)/Q(T)] × exp(-c₂E″/T)/exp(-c₂E″/296) × [1-exp(-c₂ν/T)]/[1-exp(-c₂ν/296)]
```

### 3.2 Process HITEMP Data → Absorption Coefficient Lookup Table
- [x] `scripts/process_hitemp.py` written with all steps implemented:
  - **Step 1 — Parser:** 160-char fixed-width HITRAN format; loads only lines within band wavenumber range (memory-efficient for GB-sized H₂O file)
  - **Step 2 — Temperature scaling:** Full HITRAN S(T) formula with polynomial partition function ratio Q(T0)/Q(T) (H₂O: T^1.5, linear molecules: T)
  - **Step 3 — Lorentzian + Doppler HWHM:** γ_L with pressure/self/temperature dependence; γ_D = ν × 3.581e-7 × √(T/M)
  - **Step 4 — Band averaging:** Sum of S_T across all lines in band, converted to κ [1/m] via number density n_mol = X·p/(kT)
  - **Step 5 — Lookup table:** 3D grid (28 T × 7 p × 10 X = 1960 points); output `kappa_lookup.dat`
- [ ] **Download HITEMP `.par` files first**, then run:
  ```bash
  python scripts/process_hitemp.py --species H2O CO2 CO
  ```
- [ ] Validate κ values at known (T=1000K, p=1atm, X=0.1) against published data

### 3.3 Map Absorption Coefficients onto Mesh

### 4.2 Add Multi-Band (Non-Gray) Support to `myFvDOM.C`
- [x] **Band definitions:** reads `nBands` + `bandLimits` list from `radiationProperties` in constructor
- [x] **S4 quadrature:** `buildQuadrature()` — equal-angle subdivision of θ and φ; solid angle weights `sin(θ)·dθ·dφ`
- [x] **Planck band integration:** `planckBandIntegral(T, nuLow, nuHigh)` using Chang-Rhee series fractional blackbody function (accurate to 0.1%)
- [x] **Band-specific κ:** `mesh_.lookupObject<volScalarField>("kappaBand" + name(b))` at solve time
- [x] **Outer band loop:** `calculate()` iterates bands → Planck field per cell → inner ray loop → `solveRay()`
- [x] **RTE matrix:** `fvm::div(Ji, I) + fvm::Sp(kappa, I) == kappa * Ib_band` with `Ji` built from ray direction · face normals
- [x] **Intensity storage:** `ILambda_[band][ray]` as `List<PtrList<volScalarField>>`, named `ILambda_band{b}_ray{d}`
- [x] **Energy balance:** `Rp()` returns net radiation source `sum_b[kappa_b*(4π·Ib_b − G_b)]`; `G()` returns total incident radiation

## Critical Dependencies and Watch-outs

| Risk | Mitigation |
|------|-----------|
| HITEMP H₂O file is several GB | Filter to band wavenumber range during parsing — do not load full file into RAM |
| Voigt profile computation is slow for millions of lines | Vectorize with numpy; consider TIPS approximation for Doppler/Lorentz separately |
| fvDOM compilation errors with custom changes | Compile incrementally; test gray case before adding band loop |
| Mesh interface gaps after stitchMesh | Use `checkMesh -allTopology` to detect; adjust patch tolerances in `stitchMesh` |
| kappa = 0 cells causing numerical issues | Set minimum floor (e.g., 1e-10 m⁻¹) in kappaBand fields |
| Ray directions not covering sensor | Verify sensor patch normal aligns with at least one ray direction; increase nPhi/nTheta if needed |
| Residuals not converging | Reduce `relTol`, increase `maxIter` in fvDOMCoeffs; check BCs are consistent |
